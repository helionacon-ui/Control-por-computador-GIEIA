# Control por Computador · Guía para aprobar

**Proyecto iniciado el 4 de noviembre de 2026.**

Guía de estudio interactiva de Control por Computador (UPCT, GIEyA, 3.º).

Ábrela en: https://helionacon-ui.github.io/Control-por-computador-GIEIA/

Está dividida en varias páginas: portada, una página por tema, prácticas, exámenes resueltos paso a paso, demostraciones, autoevaluación, ejercicios complementarios, formulario, glosario y plan de estudio. Todas comparten `style.css` y `app.js`, y el buscador de la portada busca en toda la guía. `guia-completa.html` es la misma guía en una sola página.

Se puede instalar como aplicación (pantalla de inicio en el móvil, «Instalar» en el ordenador) y funciona sin conexión después de abrirla una vez con internet.
