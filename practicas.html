Examen de prácticas (30 %)

Es un único examen de laboratorio por convocatoria. Las prácticas oficiales son cinco: secuencias y sistemas discretos, transformada Z, realización de controladores digitales, régimen transitorio y estacionario, y diseño de controladores digitales. Con estos comandos (MATLAB u Octave) cubres los cinco bloques y las cuestiones prácticas de los exámenes:

pkg load control                       % en Octave; en MATLAB no hace falta
T  = 0.1;
Gs = tf(1, conv([1 1],[1 10]));        % planta continua
Gz = c2d(Gs, T, 'zoh')                 % planta + ZOH -> G(z)
zero(Gz), pole(Gz)                     % para las reglas de Ragazzini

z  = tf('z', T);
Gc = (1/z) / (Gz*(1 - 1/z));           % deadbeat H = z^-1
Hcl = feedback(Gc*Gz, 1);              % lazo cerrado con realimentación unitaria
[y, t] = step(Hcl, 2);                 % respuesta a escalón
stairs(t, y); grid on; y(end)          % valor estacionario

% Secuencia de salida de un sistema discreto con entrada cualquiera
r = [0 1 1 1 0 zeros(1,15)];
[num, den] = tfdata(Hcl, 'v');
c = filter(num, den, r); stem(0:length(r)-1, c)

% Secuencias y convolución
n = 0:20; x = (n<=4); h = 0.8.^n; y = conv(x, h); stem(0:length(y)-1, y)

% Transformada Z: residuos / fracciones parciales de H(z)
[r_, p_, k_] = residuez([1 1], [1 -1 0.5])   % H(z) = (1+z^-1)/(1-z^-1+0.5z^-2)
impz([1 1], [1 -1 0.5], 10)                  % primeras muestras de h[n]

% Emulación y lugar de las raíces
Cs = tf([1 1],[1 10]);
Cz = c2d(Cs, 0.1, 'tustin')                  % también 'zoh', 'matched'
Gz = c2d(tf(1,[1 1 0]), 1, 'zoh');
rlocus(Gz); zgrid                            % lugar de las raíces con rejilla zeta/wn
stepinfo(feedback(2*Gz,1))                   % sobreimpulso, tiempo de establecimiento
Kp = dcgain(Gz)                               % constantes de error

Las prácticas de la asignatura, resueltas

Estas son las cuatro prácticas de la asignatura, más una versión anterior de la práctica 3. El examen de laboratorio te pedirá algo de este estilo: programar, simular e interpretar lo que sale. Para cada ejercicio tienes el código y el resultado que tiene que salir.

Práctica 1 · Secuencias discretas
% Ej. 1  x[n] = 2 sin(3n)
n = 0:40; x = 2*sin(3*n); stem(n,x); grid
% Ej. 2  x[n] = a^n para a = 1, -1, 2, -2, 1/2, -1/2
for a = [1 -1 2 -2 0.5 -0.5]
  figure; stem(0:10, a.^(0:10)); title(['a = ' num2str(a)]); grid
end
% Ej. 3  e^{j3n}: parte real e imaginaria
n = 0:40; subplot(2,1,1); stem(n,cos(3*n)); title('Parte real')
subplot(2,1,2); stem(n,sin(3*n)); title('Parte imaginaria')
% Ej. 6  x1 = e^{j2pi n/3}, x2 = e^{j3pi n/4}, suma
n = 0:48; x = exp(1j*2*pi*n/3) + exp(1j*3*pi*n/4); stem(n, real(x))
% Ej. 7  cos(15t) muestreada
t = 0:0.001:2; plot(t,cos(15*t)); hold on
Ts = 2*pi/(15*8); nn = 0:16; stem(nn*Ts, cos(15*nn*Ts))   % N0 = 8
EjercicioLo que tienes que contestar
1 · $2\sin3n$Amplitud 2. No es periódica: $\frac3{2\pi}\notin\mathbb Q$ (la gráfica nunca se repite exactamente).
2 · $\alpha^n$$\alpha=1$: constante. $\;-1$: alterna $\pm1$. $\;2$: crece. $\;-2$: crece alternando signo. $\;\frac12$: decae. $\;-\frac12$: decae alternando. $|\alpha|$ decide si crece o decae y el signo, si alterna: es la idea de los polos del tema 4.
3 · $e^{j3n}$Amplitud 1, no periódica por la misma razón que el ejercicio 1.
4 · $3\sin(\sqrt2\,n)$No periódica: $\frac{\sqrt2}{2\pi}$ es irracional.
5 · $\cos(k\cdot3n)$Con $\Omega_0=3$, $k=2,3,4$ dan $6$, $9$ y $12$ rad, que equivalen a $-0{,}28$, $2{,}72$ y $-0{,}57$ rad (restando $2\pi$). Las «armónicas» no van más rápido: $\cos6n$ parece más lenta que $\cos3n$. Es el aliasing en frecuencia discreta: solo importa $\Omega$ en $(-\pi,\pi]$.
6 · suma$N_1=3$, $N_2=8$ ⇒ $N=\operatorname{mcm}=24$.
7 · $\cos15t$Periódica si $\frac{T_s}{T}\in\mathbb Q$, con $T=\frac{2\pi}{15}$. Con $T_s=\frac T8$, $N_0=8$. Con $T_s=0{,}1$: $\Omega_0=1{,}5$ rad y $\frac{1{,}5}{2\pi}\notin\mathbb Q$ ⇒ no periódica. (El ejemplo del enunciado, $T_s=\frac{2\pi}5=3T$, da una secuencia constante: muestreas siempre en el mismo punto del ciclo.)
Práctica 2 · Convolución
function [y,ny] = convolucion(x,nx,h,nh)
  y  = conv(x,h);
  ny = (nx(1)+nh(1)) : (nx(end)+nh(end));
end

% Ejemplo del guion
[y,ny] = convolucion([-1 3 -1 -2], -1:2, [-2 2 0 -1 1], -1:3);
stem(ny,y)        % y = [2 -8 8 3 -8 4 1 -2] para n = -2..5

% Ej. 1
y1 = conv([1 4 8 2],[0 1 2 3 4])          % [0 1 6 19 34 44 38 8]
% Ej. 2 (x empieza en n=-1)
[y2,n2] = convolucion([1 2 1 1], -1:2, [1 1 1], 0:2)   % [1 3 4 4 2 1], n = -1..4
% Ej. 3 (Oppenheim 2.4)
a = 0.5; y3 = conv(ones(1,5), a.^(0:6)); stem(0:10, y3)

Lo que tienes que contestar. La longitud de la salida es $N+M-1$ y empieza en $n_{x,e}+n_{h,e}$. El ejemplo de la práctica da $y=\{2,-8,8,3,-8,4,1,-2\}$ desde $n=-2$; el ejercicio 1, $\{0,1,6,19,34,44,38,8\}$; el ejercicio 2, $\{1,3,4,4,2,1\}$ desde $n=-1$. El ejercicio 3 es el E55 de los ejercicios complementarios de esta guía: compara la gráfica con la fórmula por tramos (puedes usar la calculadora de convolución de la guía).

Práctica 3 · Transformada Z inversa con MATLAB
pkg load signal
% Ejemplo del guion: H(z^-1) = 4 z^-2 / (4 - z^-2)
[r,p,k] = residuez([0 0 4],[4 0 -1])       % h[n] = -4 d[n] + 2(1/2)^n + 2(-1/2)^n
h = filter([0 0 4],[4 0 -1],[1 zeros(1,9)]) % 0 0 1 0 0.25 0 0.0625 ...

% Ej. 1  H = 1/(z^2-3z+2), ROC |z|>2
h1 = filter([0 0 1],[1 -3 2],[1 zeros(1,9)])   % 0 0 1 3 7 15 31 ...
% Ej. 2  H = 1/(z^2-0.9z+0.7): polos complejos
[r,p,k] = residuez([0 0 1],[1 -0.9 0.7]); abs(p), angle(p)
% Ej. 3  H = z/(z^3-6z^2+11z-6)
h3 = filter([0 0 1],[1 -6 11 -6],[1 zeros(1,9)])
% Ej. 4 y 5
h4 = filter([0 1],[1 0 1],[1 zeros(1,9)])      % 0 1 0 -1 0 1 ...
h5 = filter([0 1],[1 -2 2],[1 zeros(1,9)])     % 0 1 2 2 0 -4 -8 -8 0 16
EjercicioSolución analítica
Ejemplo$h[n]=-4\delta[n]+2(\frac12)^n+2(-\frac12)^n$: $0,0,1,0,\frac14,0,\dots$
1 · $\frac1{z^2-3z+2}$$=\frac{1}{z-2}-\frac{1}{z-1}$ ⇒ $h[n]=(2^{n-1}-1)1[n-1]$: $0,0,1,3,7,15,\dots$
2 · $\frac1{z^2-0{,}9z+0{,}7}$Polos $re^{\pm j\theta}$ con $r=\sqrt{0{,}7}=0{,}837$ y $\theta=1{,}003$ rad. $h[n]=r^{n-2}\frac{\sin((n-1)\theta)}{\sin\theta}1[n-1]$: $0,0,1,0{,}9,0{,}11,-0{,}53,\dots$ Oscilación amortiguada, estable.
3 · $\frac{z}{(z-1)(z-2)(z-3)}$$\frac Hz$: coeficientes $\frac12,-1,\frac12$ ⇒ causal: $h[n]=\big[\frac12-2^n+\frac12 3^n\big]1[n]$: $0,0,1,6,25,90,\dots$ (Ojo: el enunciado dice ROC $|z|>2$, pero con un polo en 3 la ROC causal es $|z|>3$. Con el anillo $2<|z|<3$ el término de 3 sería izquierdo.)
4 · $\frac{z}{z^2+1}$Polos $\pm j$ sobre la circunferencia: $h[n]=\sin\frac{\pi n}2\,1[n]$. Oscila sin decaer: marginalmente estable (no es BIBO estable).
5 · $\frac{z}{z^2-2z+2}$Polos $1\pm j=\sqrt2e^{\pm j\pi/4}$ fuera del disco: $h[n]=(\sqrt2)^n\sin\frac{\pi n}4\,1[n]$. Oscilación creciente: inestable.
Práctica 4 · Sistemas de datos muestreados (y práctica 3 de 2012)
pkg load control
G1 = tf(1,[1 1]); G2 = tf(1,[1 2]); T = 1;
% Ej. 1  cascada con y sin muestreador intermedio
Ga = c2d(G1,T,'imp') * c2d(G2,T,'imp');     % con muestreador: G1(z)G2(z)
Gb = c2d(G1*G2,T,'imp');                    % sin muestreador: (G1G2)(z)
step(Ga, Gb)                                % respuestas distintas
% Ej. 2  ZOH con G = 1/(s(s+1))
Gz = c2d(tf(1,[1 1 0]),T,'zoh')             % (0.3679z+0.2642)/(z^2-1.3679z+0.3679)
% Ej. 3  'imp' frente a 'tustin'
c2d(tf(1,[1 3 2]),T,'imp'), c2d(tf(1,[1 3 2]),T,'tustin')
% Ej. 4  lazo cerrado discreto frente a continuo (Ogata B-3-19)
Hd = feedback(Gz,1); Hc = feedback(tf(1,[1 1 0]),1);
step(Hd,15); hold on; step(Hc,15)
% PID discreto (práctica 3 de 2012): Kp=1, Ki=Kd=0.2, T=1, integral por trapecio
z = tf('z',T);
Gpid = 1 + 0.2*(1-1/z)/T + 0.2*(T/2)*(1+1/z)/(1-1/z);
H = feedback(Gpid*Gz,1); step(H,30); pole(H)
EjercicioLo que tiene que salir
1 · cascadaCon muestreador intermedio, $\frac{z^2}{(z-0{,}368)(z-0{,}135)}$; sin él, $\frac{0{,}233z}{(z-0{,}368)(z-0{,}135)}$. Los mismos polos con otro numerador, así que las respuestas al escalón son distintas.
2 · ZOH$G(z)=\frac{0{,}3679z+0{,}2642}{(z-1)(z-0{,}3679)}$. Analíticamente: $\frac{(T-1+e^{-T})z+(1-e^{-T}-Te^{-T})}{(z-1)(z-e^{-T})}$.
3 · imp / tustin'imp' da $\frac{0{,}2325z}{z^2-0{,}5032z+0{,}0498}$: es la integral de contorno de Jury (invarianza al impulso). Según la versión, MATLAB/Octave lo escala por $T$; con $T=1$ coinciden. 'tustin' da otra cosa: $\frac{0{,}083(z+1)^2}{z^2-0{,}333z}$.
4 · lazo cerradoDiscreto: $\frac{0{,}3679z+0{,}2642}{z^2-z+0{,}6321}$, con $y[k]=0;\ 0{,}368;\ 1;\ 1{,}400;\ 1{,}400;\ 1{,}147;\ 0{,}894;\dots$ (sobreimpulso del 40 %). Continuo $\frac{1}{s^2+s+1}$: pico de 1,16. El discreto oscila más porque el ZOH añade retardo.
PID$G_{PID}(z)=\frac{1{,}3z^2-1{,}3z+0{,}2}{z(z-1)}$. Lazo cerrado de 4.º orden, polos de módulo $0{,}79;\ 0{,}79;\ 0{,}77;\ 0{,}11$: estable. Escalón: pico de 1,66 en $k=3$ y luego llega a 1. Ante la rampa, error final nulo, porque hay dos integradores (PID y planta): tipo 2.

La práctica 3 de 2012 hace lo mismo en Simulink: un subsistema con c2d, un bloque Zero-Order Hold delante de $G_p(z)$ y el bloque Discrete PID Controller (derivada por diferencias regresivas e integral por trapecio). El PID por trapecio es $K_p+\frac{K_d}{T}(1-z^{-1})+K_i\frac T2\frac{1+z^{-1}}{1-z^{-1}}$. El último término es justo la transformación bilineal de $\frac1s$.

Qué suele fallar en el examen de laboratorio

  • Olvidar pkg load control o pkg load signal en Octave.
  • Confundir el orden de los coeficientes: residuez y filter van en potencias de $z^{-1}$; residue y tf, en potencias de $z$.
  • Usar 'imp' cuando piden la planta con retenedor (es 'zoh').
  • No escribir la interpretación. El guion pide «Interpretación del alumno» en cada ejercicio y se puntúa.
